# somax-app — 이 repo는 더 이상 사용하지 않습니다

이 repo(`index.html.html`)는 실제 앱이 나오기 전, 사전 등록(대기 명단)을 받기 위해 만든
정적 랜딩페이지였습니다.

**실제 서비스는 여기 있습니다**: [`jungminhyunjin-max/somax`](https://github.com/jungminhyunjin-max/somax)
(Next.js 앱, somadt.com에 배포됨) — 이 repo 안에 이미 더 최신 랜딩페이지(`app/page.tsx`)가
포함되어 있고, 실제 앱 시작(`/app`)으로 바로 연결됩니다.

앞으로 랜딩페이지·제품 관련 변경은 전부 `somax` repo에서 진행해주세요. 이 repo는 과거 기록
보존 목적으로만 남겨두고, 링크가 걸린 곳이 없는지 확인되면 정리(archive/삭제)해도 됩니다.

`backend/` 폴더(추천 API 데모 코드)도 실제 서비스와는 무관하며, 참고용으로만 남아있습니다 —
실제 케어 추천 로직(톰슨 샘플링)은 `somax` repo의 `lib/bandit.ts`에 구현되어 있습니다.
